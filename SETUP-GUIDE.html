Vehicle Check: setup guide

LBH Vehicles · phone app (EN/PT) → Google Sheet → Excel · version 1.0.0

What's in the package

Folder / fileWhat it is
app/The phone app. These files get hosted on the web (Part B).
app/config.jsThe only file you edit: paste your Google web-app URL into it.
app/data.jsThe checklist items, guidance text and both languages. Edit this to change wording.
apps-script/Code.gsThe database script. It goes into your Google Sheet (Part A).

Part A: create the database (about 10 minutes)

1 Go to sheets.google.com on your computer and open a Blank spreadsheet. Name it Vehicle Checks.
2 Click Extensions ▸ Apps Script. A code editor opens. Delete everything in Code.gs, paste in the whole of apps-script/Code.gs, then click the 💾 save icon.
3 In the toolbar, pick setup from the function drop-down and click ▶ Run. Google will ask for permission:
• Review permissions → choose your account
• "Google hasn't verified this app" → Advanced → Go to … (unsafe) → Allow
This warning is normal for any script you write yourself. It only gives the script access to your own Sheet, Drive (for photos) and email (for the Excel copies).
Back in the Sheet you'll now see three tabs: Checklists, Defects and Service Records.
4 In Apps Script, click Deploy ▸ New deployment. Click the ⚙ gear and choose Web app, then set:
• Execute as: Me
• Who has access: Anyone  (this is what lets drivers submit without logging in)
Click Deploy and copy the Web app URL. It ends in /exec.
5 Open app/config.js in Notepad and replace PASTE_YOUR_WEB_APP_URL_HERE with that URL, keeping the quotes. Save.
6 To check it works, paste the URL into your browser. You should see {"ok":true,"app":"vehicle-check",…}.
If you ever edit Code.gs later: use Deploy ▸ Manage deployments ▸ ✏️ ▸ Version: New version ▸ Deploy. That keeps the same URL, so the phones don't need changing. A "New deployment" would create a new URL.

Part B: put the app online (about 10 minutes, free)

The app needs a web address so phones can install it. The easiest free option is GitHub Pages.

1 Create a free account at github.com.
2 Click + ▸ New repository. Name it vehicle-check, choose Public and click Create repository.
3 Click uploading an existing file. Open the app folder on your PC, select everything inside it (including the icons folder) and drag it into the browser. Click Commit changes.
4 Go to Settings ▸ Pages. Under "Branch", choose main and / (root), then click Save. After a minute or two your app is live at:
https://YOUR-USERNAME.github.io/vehicle-check/
Only the app's code is public. No check data is stored there; that all goes to your private Google Sheet. If you connect GitHub to Claude (claude.ai ▸ Settings ▸ Connectors), Claude can publish future updates for you directly.
Alternative to GitHub: Netlify (app.netlify.com/drop). Sign up free and drag the app folder onto the page.

Part C: install on the drivers' phones (1 minute each)

Android (Chrome): open the link → ⋮ menu → Install app (or Add to Home screen).
iPhone (Safari): open the link → Share button □↑ → Add to Home Screen.
Open the app once while there is signal. After that it works with no signal: checks are saved on the phone and send themselves automatically when signal returns. The home screen shows how many are waiting to send.

Send the drivers the link through the LBH Vehicles WhatsApp group. The app opens in Portuguese on Portuguese phones, and the EN / PT button at the top switches language at any time.

Part D: getting the data into Excel

OptionHow
Weekly Excel email (recommended)In the Google Sheet, click the Vehicle Check menu ▸ Send me an Excel copy every Monday. You get a .xlsx by email each Monday, and the subject line shows how many defects are still open. Email me an Excel copy now sends one straight away.
Download any timeIn the Sheet: File ▸ Download ▸ Microsoft Excel (.xlsx).
Live link in ExcelIn the Sheet: File ▸ Share ▸ Publish to web ▸ Entire document ▸ Microsoft Excel ▸ Publish, then copy the link. In Excel: Data ▸ From Web ▸ paste the link ▸ choose the tabs ▸ Load. Press Refresh All to update.
⚠ Anyone who has that link can read the data (names, registrations), so only use this if that's acceptable.

What you'll see in the Sheet

TabContents
ChecklistsOne row per check: vehicle, km, both inspectors, every item (✓ / X / Yes / No), oil and coolant H/L, extinguisher expiry, a Result column (green ALL OK / red PROBLEMS), Warnings for expired or soon-to-expire inspection, licence, insurance or extinguisher, and a link to the photos.
DefectsOne row per problem found, with a photo link and a Status drop-down (Open / In progress / Closed) plus Action taken and Closed on columns for the workshop to fill in.
Service RecordsThe Vehicle Service/Repair Record: each part ✓ / X with quantity and part number.

Photos are saved in Google Drive under Vehicle Check Photos ▸ [registration] ▸ [date + ID].

Changing the app later

To change checklist wording or add an item, edit app/data.js. Then open app/sw.js and change the version in const CACHE = "vehicle-check-v1.0.0" (for example to v1.0.1) so phones fetch the update. Upload just those changed files to GitHub. New items get their own column in the Sheet automatically.
Security key: APP_KEY in config.js must match APP_KEY at the top of Code.gs. If you change it, change both and redeploy (see the note in Part A).

Things that change from the paper guidelines

Guideline 6 ("computer generated lists are not acceptable") and guideline 7 (photograph the paper sheet and post it to WhatsApp) need updating for the app. Drivers can still tap Share on WhatsApp after submitting, which posts a summary (with photos on Android) to the group.
